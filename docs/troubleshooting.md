# Диагностика

## Приложение не открывается

```bash
docker compose ps
docker compose logs --tail=100 app
curl -v http://localhost:3500/api/health
```

- Порт 3500 занят: измените `HOST_PORT` (контейнер всё равно слушает 3500).
- `migrate` завершился с ошибкой: `docker compose logs migrate`; исправьте SQL/БД,
  не удаляйте volume без бэкапа.
- `health` → `db: error`: проверьте `DATABASE_URL`, пароль и `docker compose logs db`.

## Ошибка `ER_INVALID_ON_UPDATE`

MySQL 8.4 не принимает `ON UPDATE CURRENT_TIMESTAMP(3)` для некоторых колонок.
В проекте `updated_at` выставляется сервисами вручную. Не добавляйте
`.onUpdateNow()` с `fsp: 3`.

## Крайние символы/кириллица в mysql CLI

Клиент MySQL может показывать `latin1`, хотя приложение пишет `utf8mb4`. Это
отображение CLI. Проверяйте данные через API или задайте
`SET NAMES utf8mb4;` в сессии.

## PDF не формируется

- В логах `Access to local file denied`: pdfmake ограничен каталогом `uploads` и
  каталогом шрифтов Roboto. Не передавайте произвольные пути.
- PDF содержит только текст, без фото: проверьте, что позиции/изображения
  сохранились (`GET /api/orders/:id`), и пересоберите PDF из админки.
- Шрифт: Roboto берётся из `node_modules/pdfmake/fonts/Roboto`; не удаляйте пакет
  `pdfmake` из production-зависимостей.

## Снимок 3D пустой

- `Scene3D.capture()` ждёт загрузки моделей; если модель не загрузилась, рисуется
  fallback-бокс.
- Проверьте ответ `.glb`/`.stl` в Network: должен быть 200 и правильный MIME.
- WebGL недоступен (виртуальная машина/старый браузер): появится сообщение
  «WebGL-контекст потерян»; для снимков нужен браузер с WebGL.
- Для тяжёлой модели включите оптимизацию в админке.

## Модель не загружается после оптимизации

- Откройте `/admin/catalog` → товар → «3D-модель» → статус и текст ошибки.
- «Вернуть оригинал» отключает оптимизированный файл.
- Проверьте, что исходник — GLB версии 2 или STL; GLTF с внешними `.bin`/текстурами
  не оптимизируется (загрузите GLB).

## 403 CSRF_INVALID

Фронтенд должен отправлять `X-CSRF-Token` из `/api/auth/me` при каждой мутации.
Если токен устарел после перезагрузки — обновите страницу. Не отключайте CSRF
в production.

## 401/403 в админке

- `AUTH_REQUIRED` — нет cookie/сессия истекла, войдите заново.
- `FORBIDDEN` — роль не подходит. Менеджер не имеет доступа к каталогу и
  настройкам; это проверяется на сервере.
- После смены пароля/блокировки старые сессии могут быть недействительны.

## Загрузка файла отклонена

- Изображения: JPEG/PNG/WebP до 8 МБ.
- Модели: GLB/GLTF/STL до 50 МБ.
- Проверка MIME выполняется по содержимому, расширение не единственный критерий.
- Имя файла на диске — ULID; исходное имя хранится в БД.

## Восстановление после сбоя

```bash
./scripts/backup.sh
# при необходимости
./scripts/restore.sh backups/db-....sql backups/uploads-....tar.gz
docker compose restart app
```

Восстановление проверяйте сначала на тестовой БД. После отката миграций вручную
сверьте версию в `__drizzle_migrations`; миграции только вперёд.

## Медленный 3D

- Оптимизируйте модели до 50–100 тыс. треугольников.
- Ограничьте DPR (в коде уже ≤ 2).
- Закройте лишние вкладки; 20 моделей с тенями должны давать 30+ FPS на целевом
  десктопе.
- Тени — основной источник нагрузки; при необходимости уменьшите `shadow.mapSize`.

## Логи

```bash
docker compose logs -f app
docker compose logs -f migrate
docker compose logs -f db
```

Каждая ошибка 5xx содержит `requestId`. При обращении в поддержку приложите
`requestId`, время и URL.
